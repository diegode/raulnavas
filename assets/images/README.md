# Background Image

## Nighthawks by Edward Hopper

This directory should contain the background image used on the website.

### Required Image:
- **Filename**: `nighthawks.jpg`
- **Painting**: "Nighthawks" by Edward Hopper (1942)
- **Description**: Famous painting depicting people in a downtown diner late at night

### How to add the image:

1. **Download the image:**
   - Search for "Nighthawks Edward Hopper high resolution" 
   - Or visit the Art Institute of Chicago website (official source)
   - Download a high-quality version of the painting

2. **Save the image:**
   - Place it in this directory: `/assets/images/`
   - Name it: `nighthawks.jpg`

3. **Recommended specifications:**
   - Format: JPG or PNG
   - Minimum width: 1920px (for good quality on most screens)
   - File size: Optimize for web (100-500KB is usually sufficient)

### Alternative sources:
- Wikimedia Commons (public domain)
- Art Institute of Chicago (official collection)
- Search for "Nighthawks painting public domain"

### Note:
The painting is in the public domain in most countries, but verify copyright status in your jurisdiction before using.

### Image optimization:
After downloading, you can optimize the image for web:
```bash
# Using ImageMagick (if installed)
convert nighthawks.jpg -resize 1920x -quality 85 nighthawks.jpg

# Or use online tools like:
# - TinyPNG.com
# - Squoosh.app
# - CompressJPEG.com
```
